# VS2026Handbook_Chapter4

A collection of Python examples for Chapter 4 of the VS2026 Handbook. The scripts demonstrate basic input validation and everyday calculations for scenarios such as groceries, receipts, invoices, tips, temperatures, commissions, and customer messages.

## Requirements

- Python 3
- Visual Studio 2026 with Python support (optional)

## Getting started

Clone the repository and open the project in Visual Studio:

```bash
git clone https://github.com/liewvk/VS2026Handbook_Chapter4.git
cd VS2026Handbook_Chapter4
```

Alternatively, open `VS2026Handbook_Chapter4.slnx` in Visual Studio.

## Running the examples

Run individual scripts from a terminal:

```bash
python grocery.py
python tip.py
python temp_converter.py
```

## Project files

- `VS2026Handbook_Chapter4.py` — main sample script
- `grocery.py` — grocery calculation example
- `receipt.py` — receipt formatting example
- `invoice.py` — invoice calculation example
- `tip.py` — tip calculator
- `temp_converter.py` — temperature conversion example
- `commissions_summary.py` — commission summary example
- `customer_message.py` — customer message example
- `safe_input.py` — safe input helper
- `validation.py` — input validation example
